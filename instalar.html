Canal de instalação Android
Aplicativo para Android • versão 2.1

Instale a Rebeca no seu celular ou tablet

A assistente virtual do Residencial Villa Europa está disponível para consultar orientações, horários, comunicados e regras do condomínio. O aplicativo requer acesso à internet.

⬇ Baixar Rebeca 2.1 para Android

Download oficial pelo GitHub • Android 8.0 ou superior

Como instalar

  1. Toque no botão Baixar Rebeca 2.1 para Android.
  2. Após o download, abra o arquivo Rebeca-2.1-Villa-Europa-Android.apk.
  3. Se o Android solicitar, autorize temporariamente instalar aplicativos desta fonte para o navegador utilizado.
  4. Toque em Instalar, abra a Rebeca e permita o microfone apenas se desejar utilizar a voz.
Importante: esta é uma versão de testes. A instalação depende da confirmação do próprio Android; o aplicativo não ignora as proteções do sistema. A Rebeca orienta sobre piscina e churrasqueira, que integram a mesma área de lazer, mas não realiza reservas. O funcionamento completo ainda precisa ser validado em aparelhos reais.
